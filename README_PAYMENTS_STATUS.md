# Payments feature status

| Capability | Status | Notes |
|---|---|---|
| Payments home screen | Working UI | Prototype interface |
| Demo UPI ID preview | Demo only | No payment sent |
| QR scan | Placeholder | Does not open camera or decode QR |
| Real UPI transfers | Not implemented | Requires eligible partner, approvals and production APIs |
| Bank account linking / official transaction data | Not implemented | Separate Account Aggregator onboarding required |
| Bills/recharges | Not implemented | Requires biller/payment partner integration |
| Expense dashboard / CSV import | Existing working local features | Browser/device storage only unless separately configured |
| Android notification tracking | Experimental prototype | Notifications can be incomplete; not bank-confirmed |

Do not advertise the prototype as a live UPI app until partner integration, testing, approval, reconciliation, and production rollout are complete.
